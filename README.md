# duAro ゴミ自動分別システム（双腕対応）

YOLO26 による物体検出と川崎重工 duAro（双腕ロボット）を組み合わせて、  
机の上のゴミを自動で **認識 → 分類 → 担当アームを選択 → 対応する箱へ投入** するシステムです。

## ファイル構成

```
duaro/
├── camera.py                 … 双腕6点キャリブレーション＆ゴミ箱色検出
├── duaro_yolo_detector.py    … YOLO26 で物体を検出し、ゴミのカテゴリを判定
├── air.py                    … 空気ポンプ制御（ハンドの開閉）
├── duaro_waste_sorting.py    … メインプログラム（↑3つを統合して双腕を制御）
├── install.txt               … pip install コマンドのメモ
└── README.md                 … このファイル
```

| ファイル | 種類 | 単体実行 | 説明 |
|---|---|---|---|
| `camera.py` | モジュール | `python camera.py` | 机の上の6か所の目印をクリック＋ロボットを合わせて `WHERE` で座標を自動取得し、アーム1・アーム2それぞれのホモグラフィ行列と左右の境界線を `camera_calibration.json` に保存。ゴミ箱の色検出機能も持つ |
| `duaro_yolo_detector.py` | モジュール | `python duaro_yolo_detector.py` | YOLO26でカメラ映像から物体を検出し、紙ごみ/プラスチック/缶ビンに分類。単体実行でカメラテスト可能 |
| `air.py` | モジュール | `python air.py` | duAro に登録した `pump_on` / `pump_off` プログラムを実行してハンドを開閉。単体実行でポンプテスト可能 |
| `duaro_waste_sorting.py` | **メイン** | `python duaro_waste_sorting.py` | 上記3モジュールを統合し、ゴミの位置に応じて左腕/右腕を使い分けてピッキング→分別投入を制御するメインプログラム |
| `install.txt` | ドキュメント | — | `pip install` コマンドのメモ。Python から読み込まれることはない |

### 自動生成されるファイル

| ファイル | 生成元 | 内容 |
|---|---|---|
| `camera_calibration.json` | `camera.py` Mode 1 | アーム1用行列 `H1_arm1`・アーム2用行列 `H2_arm2`・左右の境界 `split_u`・校正範囲 `ranges`・測定時の先端Z `measured_z` |
| `bin_coordinates.json` | `camera.py` Mode 2 または `duaro_waste_sorting.py` 起動時 | ゴミ箱（赤・黄・青）のピクセル位置および各アームから見たロボット座標 |

## ファイルの連携（importの仕組み）

`python duaro_waste_sorting.py` を実行すると、冒頭の `import` 文で他の3ファイルが自動的に読み込まれます。  
自分で個別に実行する必要はありません。

```
duaro_waste_sorting.py（メインプログラム）
│
├── from camera import ...               ← camera.py の関数・クラス・定数を使う
│     ├── load_calibration()                 JSONから双腕キャリブレーション(Calibration)を読み込み
│     ├── detect_bins_in_frame()             ゴミ箱を色で検出
│     ├── make_bin_entry()                   ゴミ箱のピクセル位置を両アームのロボット座標に変換
│     ├── save_bin_coordinates()             ゴミ箱座標をJSONに保存
│     ├── draw_text_jp() / draw_split_line() 日本語テキスト・左右の境界線を描画
│     ├── open_camera()                      カメラを起動（DSHOW優先でMSMFエラー防止）
│     └── ARM_RIGHT / ARM_LEFT / ARM_NAMES   アーム番号(1:右腕, 2:左腕)と表示名の定数
│
├── from duaro_yolo_detector import ...  ← duaro_yolo_detector.py のクラス・定数を使う
│     ├── WasteDetector                      YOLO検出クラス（モデルを保持して何度も使う）
│     ├── CATEGORY_PAPER                     "紙ごみ" の定数
│     ├── CATEGORY_PLASTIC                   "プラスチック" の定数
│     └── CATEGORY_CAN_BOTTLE                "缶ビン" の定数
│
└── from air import ...                  ← air.py の関数を使う
      ├── pump_on()                          ポンプON（ハンドを閉じて掴む）
      └── pump_off()                         ポンプOFF（ハンドを開いて離す）
```

## セットアップ手順

### STEP 0: ライブラリのインストール（初回のみ）

コマンドプロンプトを開いて以下を実行：

```bash
cd C:\Users\tokio\Downloads\duaro
pip install ultralytics opencv-python numpy Pillow
```

### STEP 1: duAro 側の準備（初回のみ）

krtermまたはティーチペンダントで、以下の **3つのASプログラム** を登録します（アーム1・アーム2の両方から実行できるようにします）：

```
① アーム移動用
.PROGRAM goto1()
  JMOVE p1
.END

② ハンドを閉じる（掴む）
.PROGRAM pump_on()
  OPENI 1
.END

③ ハンドを開く（離す）
.PROGRAM pump_off()
  CLOSEI 1
.END
```

### STEP 2: 双腕6点カメラキャリブレーション（初回 or カメラ・机の配置を変えた時）

座標の手打ちは不要です。duAro に Telnet 接続し、`WHERE` コマンドで座標を自動取得します。

#### 事前準備

机の上に目印（シールなど）を **6か所** 貼ります：
- **右側 2か所**（上寄り・下寄り）：アーム1（右腕）が届く位置
- **中央 2か所**（上寄り・下寄り）：**アーム1・アーム2の両方が届く位置**（※この2点の平均X座標が左右の担当境界線になります）
- **左側 2か所**（上寄り・下寄り）：アーム2（左腕）が届く位置

#### 実行

```bash
cd C:\Users\tokio\Downloads\duaro
python camera.py
```

#### 操作

1. メニューで `1`（双腕6点キャリブレーション）または `3`（キャリブレーション→ゴミ箱検出）を選択
2. カメラ番号を聞かれるのでそのまま Enter（デフォルト: 1）
3. 画面の案内に従って **6つのステップ** を進める：
   - **右-上 / 右-下**：映像上の目印をクリックして Enter → アーム1（右腕）の先端を目印の真上に合わせて Enter
   - **中央-上 / 中央-下**：映像上の目印をクリックして Enter → アーム1を合わせて Enter → 同じ目印にアーム2も合わせて Enter
   - **左-上 / 左-下**：映像上の目印をクリックして Enter → アーム2（左腕）の先端を目印の真上に合わせて Enter
4. 合計8回の座標取得が終わると、アーム1用行列 `H1`・アーム2用行列 `H2`・左右の境界 `split_u` が計算され、`camera_calibration.json` が自動生成される

## 使い方

### 本番実行

```bash
cd C:\Users\tokio\Downloads\duaro
python duaro_waste_sorting.py
```

### 起動時に自動的に行われること

1. `camera_calibration.json` を読み込み（双腕キャリブレーションデータ・左右の境界線）
2. カメラを起動
3. カメラ映像からゴミ箱（赤・黄・青）を色で自動検出 → 両アームそれぞれのロボット座標に変換して `bin_coordinates.json` に保存
4. duAro にネットワーク接続（`192.168.0.2:23`）
5. アーム1・アーム2 両方のモータ電源 ON（`ZPOWER 1: ON` / `ZPOWER 2: ON`）
6. YOLO26 モデルを読み込み（初回は数秒かかる）
7. カメラ映像ウィンドウが開く（画面中央に左右の担当境界線が表示される）→ **ここからキー操作で制御**

### 全自動分別の流れ（`a` キー）

```
'a' キーを押す
  ↓
カメラでゴミを検出（例: 紙コップ → 紙ごみ）
  ↓
物体のピクセル位置が境界線より右なら「アーム1(右腕)」、左なら「アーム2(左腕)」を選択
  ↓
【衝突防止】もう片方のアームが待機位置にいなければ、先に待機位置(Z=430mm)へ退避
  ↓
担当アームが安全上空(Z=430mm)でゴミの真上へ平面移動
  ↓
垂直下降(Z=298mm) → ポンプON（掴む）→ 安全上空(Z=430mm)へ上昇
  ↓
対応する箱（例: 青の箱）の上空(Z=430mm)へ平面移動
  ↓
投下高さ(Z=430mm)でポンプOFF（離す = 投下）
  ↓
担当アームが待機位置(Z=430mm)へ戻る
  ↓
次のゴミを探す…（あれば繰り返し）
  ↓
5回連続で何も見つからない →「全完了！」
```

## キー操作一覧

> **ポイント**: すべてのキー操作は、**OpenCVのカメラウィンドウ側・ターミナル（黒い画面）側のどちらにフォーカスがあっても反応**します。また、日本語IMEが**全角モードのまま（`ｓ` `ａ` `ｒ` `ｑ`）でも自動的に認識**されます。

### camera.py（キャリブレーション・ゴミ箱検出時）

| キー | 動作 |
|---|---|
| 左クリック | 目印の位置をクリック |
| `Enter` / `Space` / `s` | クリック位置の確定・アーム位置合わせの確定・ゴミ箱検出の保存 |
| `r` | クリックのやり直し / ゴミ箱の再検出 |
| `q` / `ESC` | 中断 |

### duaro_waste_sorting.py（本番実行時）

| キー | 動作 |
|---|---|
| `s` | **手動モード** — 画面に映っているゴミを1個だけ分別 |
| `a` | **全自動モード** — ゴミがなくなるまで自動で繰り返す |
| `q` / `ESC` | プログラム終了（全自動モード中は緊急停止） |

### air.py（ポンプ単体テスト時）

| キー | 動作 |
|---|---|
| `p` | ポンプ ON（ハンドを閉じる） |
| `o` | ポンプ OFF（ハンドを開く） |
| `q` | 終了 |

## 設定パラメータ

`duaro_waste_sorting.py` の冒頭で以下のパラメータを調整できます。

### duAro 接続・プログラム設定

| 変数名 | 初期値 | 説明 |
|---|---|---|
| `ROBOT_IP` | `"192.168.0.2"` | duAro の IP アドレス |
| `ROBOT_PORT` | `23` | Telnet ポート番号 |
| `TIMEOUT` | `10` | 接続タイムアウト（秒） |
| `ARMS` | `(1, 2)` | 使用するアーム番号（1: 右腕 / 2: 左腕） |
| `ARM_PROGRAMS` | `pose:"p1", goto:"goto1", pump_on:"pump_on", pump_off:"pump_off"` | アームごとのポーズ変数名・ASプログラム名 |
| `CAMERA_INDEX` | `1` | カメラ番号（外部カメラ = 1） |
| `REACH_CHECK` | `True` | キャリブレーション範囲外の物体を安全のためスキップするか |

### 高さ・待機位置設定（単位: mm / アームごと）

| 変数名 | 初期値 | 説明 |
|---|---|---|
| `ARM_Z[arm]["table_limit"]` | `294.0` | 机の表面限界（これより下へは絶対に下げない安全リミッター） |
| `ARM_Z[arm]["transit"]` | `430.0` | 平面移動（X, Y移動）時の固定安全高さ |
| `ARM_Z[arm]["grasp"]` | `298.0` | 物体を掴む高さ（机面294mmより4mm上） |
| `ARM_Z[arm]["bin_drop"]` | `350.0` | ゴミ箱の真上で垂直下降してゴミを離す投下高さ |
| `HOME_POS[1]` / `HOME_POS[2]` | 起動時自動取得 | 起動時に `WHERE` で取得した各アームの初期位置 `(X, Y)` ＋ 安全高さ `Z=430.0` |

### 全自動モード設定

| 変数名 | 初期値 | 説明 |
|---|---|---|
| `AUTO_NO_DETECT_LIMIT` | `5` | 連続で何回未検出なら「全完了」と判断するか |
| `AUTO_STABILIZE_WAIT` | `1.0` | 分別後、次の検出前の待機時間（秒） |
| `AUTO_MAX_FAILURES` | `3` | 連続失敗がこの回数に達したら自動停止 |

## YOLO分別対応表

`duaro_yolo_detector.py` の `CLASS_TO_CATEGORY` で定義。  
YOLO26（COCO データセット）の検出クラス名をゴミのカテゴリに対応させています。

| YOLO 検出クラス名 | 分別カテゴリ | 投入先 | 枠の色 |
|---|---|---|---|
| `book` | 紙ごみ | 青の箱 | 水色 |
| `cup` | 紙ごみ | 青の箱 | 水色 |
| `toothbrush` | プラスチック | 黄の箱 | 黄色 |
| `mouse` | プラスチック | 黄の箱 | 黄色 |
| `bottle` | 缶ビン | 赤の箱 | 赤色 |
| `wine glass` | 缶ビン | 赤の箱 | 赤色 |

カスタム学習モデルを使う場合は `CLASS_TO_CATEGORY` のキーを自分のモデルのクラス名に変更してください。

## トラブルシューティング

### `ModuleNotFoundError: No module named 'cv2'`
ライブラリが未インストール。以下を実行：
```bash
pip install ultralytics opencv-python numpy Pillow
```

### `ModuleNotFoundError: No module named 'camera'`
`camera.py` が `duaro_waste_sorting.py` と同じフォルダにない。  
全ファイルが同じ `duaro` フォルダにあることを確認。

### `FileNotFoundError` または `古い形式のキャリブレーションです`
双腕キャリブレーションが未実施、または片腕時代の古い `camera_calibration.json` が残っている。  
先に `python camera.py` を実行し、メニュー `1`（双腕6点キャリブレーション）を行う。

### `[ERROR] カメラを開けませんでした`
USB カメラが接続されていないか、他のアプリがカメラを使用中、またはカメラ番号が違う。  
別のカメラ番号（`0` や `2`）を試す場合は `CAMERA_INDEX` を変更。

### `[ERROR] 接続拒否: 192.168.0.2:23 に接続できません`
duAro の電源が入っていない、またはLAN ケーブルが未接続。  
PC と duAro が同じネットワークにいることを確認。

### `[ERROR] ロボット異常停止`
duAro 側でエラーが発生（動作範囲外など）。  
ティーチペンダントでエラーを解除し、`HOME_POS` や `ARM_Z` の値、およびゴミ箱が両アームの届く中央に置かれているかを見直す。

### 物体が「範囲外!」と表示されてスキップされる
キャリブレーション時に貼った6か所の目印の外側に物体が置かれている。  
目印の内側にゴミを置くか、机のより広い範囲に目印を貼り直してキャリブレーションを行う。

### ゴミ箱が検出されない
照明条件が合っていない可能性。  
`camera.py` の `BIN_COLOR_RANGES`（HSV の上下限値）を環境に合わせて調整。

### 特定の物体が分別されない
`duaro_yolo_detector.py` の `CLASS_TO_CATEGORY` にそのクラス名が登録されていない。  
YOLO が検出するクラス名（COCO データセット80クラス）を確認して追加する。
